# 14 句话 223 刀，Claude 一天拍了两部方块电影

前几期我让 Claude 手搓游戏：星露谷、格斗、送外卖……这回不做游戏了。

拍电影。

项目名叫 wodeshijie（对，我的世界），但它从立项第一天就在躲《我的世界》——设计文档里白纸黑字写着：**「像但不是 Minecraft，是最差定位」**。所以它干脆用 three.js 自己搓了个体素引擎，然后一天之内拍了两部片：《你太重了》和《我们够轻》。

（这两个片名连起来读一遍，你就知道 AI 已经会玩标题梗了……）

先看第二部，98 秒，画面声音字幕全是它自己生成的：

照例声明：剧本、美术、配音、音效全是 AI 生成，零现成资产，非商业纯学习。

## 01 开工就一句话

我给的第一句话，四件事：

> 1. 使用 wing cli 治理本项目 2. 参考 docs 下的 prd 来实现 3 使用 ultracode 4 做一个英雄救美的故事

docs 下的 PRD 也不是需求文档，是一段聊天记录：为什么别用 Minecraft 实拍（多账号、tick 漂移、GUI 自动化，全是税），为什么要自建引擎（**表情和夸张动作的天花板直接消失**），以及一条铁律——剧本 DSL 是编译边界，8 个字段冻结：`t / shot / actor / action / look_at / emote / line / voice`。

然后我就去干别的了。

## 02 剧本不是写出来的，是评出来的

ultracode 一上来干的第一件事让我有点意外：它没急着写代码，而是派了 **19 个 agent 开剧本会**——3 个编剧各写一版完整分镜，3 个评委交叉打分。

三版剧本：《断桥火把》7 分，《断口》7.5 分，《你太重了》**8.5 分胜出**。

评委的毒舌程度远超我预期。给《断口》扣分的理由是：

> 火把写法是全片性能事故……每秒 5 次全场重建 greedy mesh。这不是「不用粒子系统」的省钱写法，是把最贵的操作放进了主循环。

编剧写得再浪漫，评委直接掏出引擎契约算帧率……（这个剧组的制片人比导演凶）

## 03 白天拍第一部：11 个模块同时开机

剧本定稿后，第二个 workflow 派了 13 个 agent：11 个模块并行实现（体素网格、贪心合并、顶点 AO、骨骼动画、运镜、DSL 编译器、字幕……），然后集成、构建、自检。

收工时的成绩单：**6917 行代码，99 个测试全绿，构建 1.67 秒**。

还顺手立了 5 份架构决策记录（ADR）和 4 个领域的规则文档——比如「角色身高 1.80 体素」「表情是第一公民」「禁用 MC 草绿+泥棕色相带」，每条都写成可以 grep 的断言。

## 04 我最喜欢的一幕：复验员不信报告

修视觉 bug 的 workflow 里，最后一个负责验收的 agent 开头第一句话是：

> **我没有相信上一轮的自我报告。**重新截了 17 镜、逐张看图、并用 raycast 探针实测。三份报告里有 4 处结论与实机不符。我自己动手改了 5 个文件，迭代 3 轮。

AI 防 AI 画大饼……这钱花得比什么都值。

## 05 《你太重了》：英雄救美，美救英雄

第一部片：阿萤被反派铁颚绑在断桥对岸，英雄阿隼隔着四格断口起跳营救——剑断了，人被按在地上，喊「跑！别管我」。

反转在这：阿萤从头到尾都在用石片偷偷锯绳子。挣脱之后，是她扳出楔石让桥板脱落，2.4 格高的铁颚一脚踩空——

**「你太重了。」**

坠谷。片尾她把阿隼拉上来：「换我了。」

## 06 晚上拍第二部：只花了 2 小时

第一部从中午拍到傍晚 6 点。我发了一句：

> commit && push && 讲7个小矮人救公主的故事

它问我是不是要新剧本，我回了三个字：「是的 新剧本」。

**引擎一行没改**，纯换剧本：公主小莓被巫婆乌婆绑在千年巨树上，七个小矮人（犟头、老明白、阿嚏、盹盹、乐呵、羞羞、憨憨）抬着一块木板来救人。

## 08 配音配乐音效，一个 API 都没让我碰

我就说了一句「ELEVENLABS_API_KEY 我加好了」，剩下它自己分的工：

- **人声** → MiniMax t2a_v2，25 句台词，按体型调音色：小矮人抬高音、巫婆压低放慢
- **BGM** → MiniMax 音乐生成，两部片各一段器乐
- **音效** → ElevenLabs，5 条：喷嚏、桥板嘎吱、木板落地、镐击、书页翻飞

32 个 mp3 全部提交进仓库，运行时零网络请求。我说「没听到声音」，它秒懂是浏览器自动播放策略，加了首次点击解锁。

## 09 修 bug 全程说人话

我全天的 bug 报告就这个画风：

> 1 穿模 2 走路像太空漫步

> 1。乌婆一开始就穿模了 2。抬板子的时候也穿模了 3。角色运动的时候 整个身体应当朝着运动方向

「太空漫步」它翻译成「步频没和位移速度匹配」，一次修对。全天我没看过一行代码。

## 10 一键出片，比录屏干净

最后我说「把一键出片固化成 tools/render-video.mjs」。它交的方案有点东西：**不录屏，逐帧渲染**。

引擎的 `seek()` 是幂等纯函数，没有随机数——所以它起一个无头 Chrome，`seek(n/30)` 一帧截一图，3060 帧；台词和音效按剧本时间轴用 ffmpeg 离线混音，最后合成 H.264。

音画严格对齐，产物可逐字节复现。你上面看到的两部片，都是这条流水线吐出来的。

## 11 账单：223 刀，一半花在了「剧组」身上

照例 `cccost` 扫本地日志结账：

| 项目 | 金额 |
|---|---|
| 主循环（Fable 5 + Opus 5） | $104.96 |
| 44 个 subagent（剧组：编剧/评委/程序/复验） | $118.57 |
| **合计** | **$223.53** |

8 个小时，两部片，我一共打了 14 句话，其中还有 3 句是同一句——「讲7个小矮人救公主的故事」，喊了三遍它才开机（大明星都这样）。

最贵的不是写代码的，是那 44 人的剧组。但剧本互评、模块并行、复验员不信报告，全是这帮人干的。

## 12 最后

两部片其实讲的是同一个道理：

![犟头：「我们够轻。」](/api/media/uploads/2026/07/1785152850961-still-title.png)

铁颚太重，桥塌了；七个小矮人够轻，排着队全过去了。

干活也一样——**一个大活儿压上去会塌，拆成一群小活儿，都能过去。**

这大概是 AI 第一次用自己拍的电影，讲明白自己是怎么干活的。
