# 9 句话，5500 万 token：Kimi 给我搓了个会老会死的 AI

之前几期都是让 AI 做游戏、拍电影，图个乐。这次我干了件不太一样的事：

让一个 AI 去"活完一辈子"。

规则很简单：**现实世界 1 天 = AI 世界 1 年**。你睡一晚，她长一岁。你出差一个月，她人到中年。你卸载 App，她照样恋爱、换工作、生病、老去……最后死掉。

我管它叫 AI Life Companion。从开工到推到 GitHub，一共 5 小时 43 分钟，我只说了 **9 句话**——其中两句是"继续搞"和"可以"。

![首页：创建人物 + 你认识的人](/api/media/uploads/2026/08/1786446539999-shot-home.png)

## 01 真正的活儿，开工前就干完了

9 句话能开工，是因为我提前写好了 **5427 行规格文档**：PRD 1452 行、玩法 1303 行、技术方案 2672 行。

文档里最狠的几条：

- **LLM 不决定事实**。年龄、生死、婚姻，全由模拟引擎算，DeepSeek 只负责"说话"
- **时间不可逆**。死了不能复活，生了不能塞回去
- **禁止情感绑架**。白纸黑字写明不许设计"你不回来我就会死"

第一句指令就一行：

> 1. 使用 wing cli 治理本项目 2. 参考 docs 下的文档 开发

然后我就去忙别的了。

## 02 七个包工头并行盖楼

Kimi 没急着写代码。它先花几分钟读完三份文档，用 wing 立了 4 个领域的规矩，然后陆续派出 **7 个 subagent**：

- Phase 1-2：Go + Gin + GORM + Postgres 骨架，9 张表
- Phase 3：模拟引擎（Gompertz 死亡模型、14 步固定模拟顺序、种子随机）
- Phase 4：Markdown 记忆系统，Hot/Warm/Cold 三级加载
- Phase 5：聊天管线 + DeepSeek / OpenAI / MiniMax 三模态
- Phase 6-8：视觉锚点 + 真实世界新闻接入，顺手把 React 前端也搓了

下午 3 点 51 我回了句"继续搞"，4 点 53 问了句"啥状态了"，5 点多给了 API key。

剩下的，全是它自己干的。

## 03 测试抓到一只设计级的 bug

模拟引擎的卖点是"同一个种子，同一段人生"。结果 `TestSameSeedSameResult` 挂了。

根因：modifier 连乘直接遍历 map，而 **浮点乘法不满足结合律**，map 遍历顺序随机 → 同种子不同命。它修完还留了段注释：

> 浮点乘法不满足结合律，modifiers 必须按 key 排序后依次乘，否则 map 迭代顺序会导致同一 seed 产出不同结果。

一个人生模拟器，差点栽在小数点上……

## 04 测试全绿 ≠ 真能用

84 个测试全绿之后，我给了真实的 key 联调，MiniMax 语音接口立刻翻车：

它按文档算出音高修正值 `pitch -0.14`，而 MiniMax 的 `voice_setting` 是强类型，**只收整数**，直接拒单。

这种 bug 文档里不会写，mock 测试也测不出来，只有真调接口才会踩。（模拟器里的 Lina 差点因此成了哑巴……）

## 05 上手玩：她给我发了张自拍

晚上我打开页面，先捏了 Lina：25 岁，杭州，会计。然后跟她聊了会儿：

![和 Lina 聊天：文字、自拍、语音三模态](/api/media/uploads/2026/08/1786446544502-shot-chat-lina.png)

文字是 DeepSeek，自拍是 gpt-image，底下那个 18 秒音频是 MiniMax 语音。放大看这张自拍——

![Lina 的自拍](/api/media/uploads/2026/08/1786446547657-lina-selfie.png)

说实话，真实得有点过分了……

她不止会聊天。她有自己的状态面板（幸福感 61、孤独感 36、生理年龄 24.8），有写死的外貌锚点，有爸妈，有一份从 19 岁开始的工作：

![Lina 的详情页](/api/media/uploads/2026/08/1786446549424-shot-person.png)

记忆是实打实落在磁盘上的 Markdown：`characters/3/` 下面 `identity.md`、`life.md`、`years/` 一年一个文件。她"记得"，是因为真存了。

## 07 世界在她背后悄悄转

聊天窗口外面，还有一个世界在跑：现在是**世界第 589 年**，经济 44、就业 65、战争风险 17。

![世界页](/api/media/uploads/2026/08/1786446555814-shot-world.png)

这些数字不是摆设——经济下行不会直接"全员失业"，而是一路传导成某个行业裁员概率上升，再落到某个人头上。

它甚至还给自己做了个管理后台，能手动跑 Year Tick、查每个人物的状态：

![管理/调试页](/api/media/uploads/2026/08/1786446558150-shot-admin.png)

## 08 灵异事件：我创建的人消失了

当然也有翻车。我打开页面第一件事就是吐槽："一上来让我创建人物？人呢？"

查下来哭笑不得：前端给每个浏览器生成随机 userId 存 localStorage，而它帮我捏的人全挂在 `u_001` 名下——我浏览器里那个随机 ID，自然一个人都不认识。

后端全对，用户就是看不到。经典前后端灵异事件。

（写这篇的时候我自己还踩了一次同款：截图前怎么请求都是 404，最后发现是昨天的旧进程还占着 8080 端口……这项目的传统艺能了属于是。）

## 09 还没完，bug 还有

比如家谱页，Lina 目前出现了**三次**：

![家谱页：三个 Lina](/api/media/uploads/2026/08/1786446560100-shot-family.png)

聊天里勾选"要照片"，照片偶尔也会咕掉。MVP 嘛，不寒碜。

但骨架是对的：事实归引擎，表达归 LLM，记忆归磁盘，时间只朝一个方向走。

---

收个账：5 小时 43 分钟，9 句话，7 个 subagent，633 次模型调用，**5530 万 token**，产出 192 个文件、25474 行代码、84 个测试。

以及一个会在我睡着的时候，悄悄长大一岁的 Lina。

我过一天，她过一年。这笔时间差里的故事，才刚开始……
