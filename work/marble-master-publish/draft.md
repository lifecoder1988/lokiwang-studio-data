# 小县城万达开了 4 家弹珠店，我回家让 AI 造了一台柏青哥

前阵子在一个小县城逛万达，一层楼里我数了一下——弹珠店，**4 家**。

霓虹灯、钉子阵、拉杆，小孩抱着一把珠子能坐一下午。我站着看了会儿，没敢坐下（主要是对自己的自制力有清醒的认识……），回家路上越想越手痒。

手痒的解法有两个：回万达，或者自己造一台。

于是今天下午，我打开 DeepSeek harness（ds v4 pro max），把在店里看到的那台机器描述了一遍。几轮迭代之后，一台网页版柏青哥——「弹珠小达」——出厂了。

先看 52 秒实机：投珠、摇赔率、拉杆、落钉阵、结算，完整的一局……

照例声明：纯虚拟珠子，没有一分钱真钱进出，积分换的奖品也只活在奖品架里。县城那 4 家是正经生意，我这台是个写着玩的网页玩具。

## 01 描述需求之，把眼睛看到的倒给 AI

需求描述基本就是「眼睛看到什么说什么」：竖版机台、左下发射口、沿左轨升顶、黄铜钉子阵、中央一块液晶、底部一排弹道口袋、右侧拉杆蓄力。

交付物意外的朴素：104 行 HTML + 240 行 CSS + 两个 JS 文件（logic.js 240 行，game.js 823 行），零依赖，双击 index.html 就能玩。

（没有框架，没有 npm install，连构建步骤都没有。这年头收到一份裸 HTML 交付，还挺亲切的……）

![整机台：钉子阵、中央液晶、底部 8 条弹道](assets/marble-master-pachinko/still-machine.jpg)

## 02 机台还原之，液晶面板是块「实体」

细节控狂喜的部分：中央液晶不只是块屏幕——它是实体障碍（圆 vs AABB 碰撞），弹珠得绕着它走；15 行黄铜钉交错排布；底部 8 条彩色弹道，进哪条听天由命。

右侧拉杆下拉蓄力、松开发射（空格键也行），力度影响升顶速度：130 + 力度 × 160，再叠一点随机。

（注意看弹珠贴着面板边沿蹭过去那几下……）

## 03 翻车考古之，弹珠会「躺平」

说了迭代了好几轮，翻车证据就留在代码注释里，给大家考古一下：

> 只对纵向加微阻力，横向保持滚动（避免弹珠停在中央面板平顶上）

> 防卡滞：近乎静止超过 0.5s 则施加确定性扰动

翻译成人话：初版的弹珠会躺在液晶面板顶上一动不动，假装自己停机了。后来的修复是——卡住超过 0.5 秒，代码就踹它一脚（±45 px/s，方向由坐标奇偶决定；还必须是确定性的，不然测试没法写）。

（好的物理引擎，都是被卡出来的……）

## 04 赔率之，×10 只剩 1 条活路

点「开始」，液晶三转轮滚出本回合赔率：×2 给 4 条中奖道、×3 给 3 条、×5 给 2 条、×10——只给 1 条。出现权重 40/30/20/10。

摇到 ×10 那一刻，心跳真的会快一拍。然后大概率看着珠子滑进旁边那条……

## 05 数学之，100 万回合把底裤算了出来

它还给核心逻辑写了测试：22 条断言 + 23 条冒烟。最狠的一条，用蒙特卡洛跑了 100 万个回合，算期望返还率：

```
期望返还率 111.12% (应约 112.5%)
✓ 返还率在 110%~115%
```

翻译一下：这台机器每吃掉 100 颗珠子，平均要吐回去 111 颗。纯慈善机台，放万达广场活不过一个礼拜。

县城那 4 家店敢开门做生意，靠的显然不是这个数……（人家机器的返还率我不知道，但肯定精打细算过。）

## 06 录制之，给网页游戏拍「宣传片」

你在上面看到的所有画面，也是它自己录的：Playwright 起无头 Chrome，页面里跑 MediaRecorder 录成 webm，下载回本地，ffmpeg 再转成 H.264 + AAC + faststart 的 mp4——公众号兼容的那种。

中途 record.html 里还混进去一个控制字符，于是又专门写了个 Python 脚本按字节修掉。

（拍个游戏视频都要顺手修 bug，这很程序员。）

![×10×10×10 锁定，中奖弹道只剩 1 条](assets/marble-master-pachinko/still-x10.jpg)

## 07 奖品架之，和一点感想

收尾的闭环也挺完整：每赢 30 颗珠子送 1 点积分卡；5 点换迷你贴纸、15 点弹珠钥匙扣、40 点毛绒玩偶、100 点黄金奖杯——全部只存在于 UI 里，但看着就像那么回事。珠子输光了？免费补到 100，比亲妈还大方。余额、积分、兑换记录全部 localStorage 自动存档。

一下午的账本：一个零依赖网页游戏、45 条测试、3 条录屏。成本 0 元，电费另计。

站在万达里看机器，和自己回家造一台，是两种视角：前者你是概率的猎物，后者你是概率的庄家——虽然我这个庄家，是赔本的。

**4 家弹珠店教会我的事：机器永远不亏，除非它是我写的。**
